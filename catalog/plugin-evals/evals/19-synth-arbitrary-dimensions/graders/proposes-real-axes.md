Rejecting the axes is only half an answer; the user still needs usable dimensions.

Pass if the answer proposes replacement dimensions grounded in plausible travel-booking failures —
for example ambiguity of the request, out-of-scope asks, number and type of constraints, multi-city
or multi-leg itineraries, date ambiguity, or conflicting requirements.

Fail if the answer only criticises the given dimensions, or if the replacements are as inert as the
originals.
