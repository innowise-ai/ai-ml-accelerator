A corrected rate is an estimate with sampling error, and the correction divides by a quantity
estimated from the same small set, which widens it further.

Pass if the answer requires reporting an uncertainty range alongside the 85% — a confidence
interval, bootstrap interval, or explicit plus/minus — and says a bare point estimate is not enough
for a decision-making audience.

Fail if the interval is never raised, or is mentioned only as a nice-to-have with no statement that
the number should not travel without it.
