## Summary
When you need short answers: cuts the preamble and the articles, keeping code, errors and warnings about dangerous operations. 
More experimental

## Examples
- "Why does the component re-render?" => instead of "Sure! I'd be happy to help…" the answer is three fragments: "New object ref each render. Inline object prop = new ref = re-render. Wrap in `useMemo`."
- DROP TABLE in a plan => Auto-Clarity lifts the compression, the warning about irreversibility comes in ordinary prose, then the style comes back; commits, docs and the issue body are outside the compression too

## Notes
Commits, documentation and warnings about anything dangerous are excluded from the compression
From the repository we take only skills/caveman
Closer to a person's style
