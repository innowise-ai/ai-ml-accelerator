Lists and tuples are both ordered sequences. You index, slice and iterate over them the same way. The main difference is that **lists are mutable and tuples are immutable**, and most of the other differences come from that.

| | List | Tuple |
|---|---|---|
| Syntax | `[1, 2, 3]` | `(1, 2, 3)`, or just `1, 2, 3` |
| Mutable? | Yes: you can add, remove or reassign items | No: fixed once created |
| Methods | Many (`append`, `extend`, `insert`, `remove`, `pop`, `sort`, `reverse`, …) | Only `count` and `index` |
| Hashable? | No, so it can't be a dict key or set member | Yes, if all its items are hashable |
| Memory/speed | A bit larger, because it keeps spare room to grow | Smaller, and slightly faster to create |
| Typical use | A collection of similar items that changes over time | A fixed group of values, often of different types (a record) |

```python
nums = [1, 2, 3]
nums.append(4)        # fine
nums[0] = 99          # fine

point = (3, 4)
point[0] = 5          # TypeError: 'tuple' object does not support item assignment

locations = {(40.7, -74.0): "NYC"}   # tuple as dict key: OK
locations = {[40.7, -74.0]: "NYC"}   # TypeError: unhashable type: 'list'
```

**Things to watch for:**
